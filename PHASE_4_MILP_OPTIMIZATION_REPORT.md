## 1. Executive Summary & Core Objective

Phase 4 of **Q-MADSS** implements, validates, and audits the **Classical Mixed-Integer Linear Programming (MILP) Portfolio Optimization Engine**. The engine takes district-specific candidate strategy pools generated by Phase 3 for all 38 administrative districts of Tamil Nadu and solves for the mathematically optimal adaptation strategy portfolio under budget, portfolio size ($K \le 5$), dependency ($x_A \le x_B$), and mutual exclusion conflict ($x_A + x_B \le 1$) constraints.

The core question answered by Phase 4 is:
> *"Given the feasible candidate strategies for a particular district in Tamil Nadu, which combination of strategies maximizes the validated adaptation objective while satisfying budget, portfolio-size, dependency, conflict, and resource constraints?"*

## 5. MILP Mathematical Formulation

For district $d$ with candidate strategy set $\mathcal{C}_d = \{1, 2, \dots, N_d\}$:

$$\text{Maximize } Z_d = \sum_{i \in \mathcal{C}_d} c_i x_i$$

$$\text{Subject to:}$$
$$\sum_{i \in \mathcal{C}_d} x_i \le K_d \quad (K_d = 5)$$
$$x_A \le x_B \quad \forall (A, B) \in \mathcal{D}_d \quad (\text{Dependency: Strategy } A \text{ requires } B)$$
$$x_A + x_B \le 1 \quad \forall (A, B) \in \mathcal{C}NF_d \quad (\text{Conflict: Strategy } A \text{ and } B \text{ mutually exclusive})$$
$$x_i \in \{0, 1\} \quad \forall i \in \mathcal{C}_d$$
