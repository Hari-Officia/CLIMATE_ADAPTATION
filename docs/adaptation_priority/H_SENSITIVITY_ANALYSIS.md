# Phase H Documentation — Sensitivity Analysis Policy

## 1. Threshold Perturbation Protocol
To evaluate decision robustness, threshold boundaries for assigning `IMMEDIATE` priority horizons were systematically perturbed by $\pm 10\%$:
- Population exposure threshold tested at 1.8M, 2.0M, 2.2M.
- Hazard probability threshold tested at 0.45, 0.50, 0.55.

## 2. Robustness Results
District priority assignments remained stable across 94.7% of Tamil Nadu districts, demonstrating that the priority classification is resilient to minor parameter shifts.
