# Phase H Documentation — Weighting Policy

## 1. Weighting Prohibition
No subjective scalar weights (e.g. 0.4 * Hazard + 0.3 * Exposure + 0.3 * Vulnerability) are applied in Phase H. Weight assignment is arbitrary without stakeholder multi-criteria optimization, which belongs downstream in Phase I and Phase J decision trade-off modeling.

## 2. Pillar Independence
All four pillars retain equal analytical authority in driver extraction rules, avoiding unintentional suppression of high-hazard rural regions or under-populated coastal zones.
