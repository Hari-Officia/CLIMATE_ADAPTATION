# Phase I Documentation — Scope & System Limitations

## 1. System Scope Boundaries
- **Adaptation Only**: Strictly excludes climate mitigation, carbon offset credit calculation, and renewable energy generation modeling.
- **No Optimization in Phase I**: QUBO formulation (Phase L) and QAOA quantum execution (Phase M) are prohibited in Phase I.

## 2. Documented Data Gaps
- `REV-001`: Cool roof thermal reduction metric requires local microclimate field-trial validation.
- `GAP-LIDAR-001`: LiDAR micro-elevation data gap for coastal taluk inundation modeling.
