# Phase I Documentation — Qualitative Uncertainty Handling

## 1. Zero-Fabrication Protocol
Phase I explicitly prohibits generating scalar certainty scores (e.g. `certainty = 0.85`) without empirical data.

## 2. Qualitative Uncertainty Levels
- `LOW`: Multi-site field validated with Tier 1/2 evidence.
- `MEDIUM`: Extrapolated from regional pilot studies.
- `HIGH` / `UNCERTAIN`: Peer-review flag active (`REQUIRES_REVIEW`).
