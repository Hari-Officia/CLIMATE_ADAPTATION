# Phase I Documentation — Strategy Relationships & Interactions

## 1. Relationship Classifications
- `COMPLEMENTARY`: Strategies enhance mutual effectiveness when co-deployed (e.g. drain desilting + stormwater network expansion).
- `SYNERGISTIC`: Combined deployment yields non-linear benefits (e.g. rooftop rainwater harvesting + lake restoration).
- `DEPENDENT`: Prerequisites required prior to deployment (e.g. floodplain zoning required before urban wetland restoration).
- `CONFLICTING`: Incompatible strategies requiring downstream constraint enforcement.

## 2. Representation
Mapped in `config/master/strategy_relationships.json` and served via `/api/v1/strategy-relationships`.
