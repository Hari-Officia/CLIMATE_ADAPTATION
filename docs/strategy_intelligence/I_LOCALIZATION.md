# Phase I Documentation — Tamil Nadu Localization

## 1. Local Adaptation Interventions
- Traditional *erie* tank structures and lake desilting (`STR-WTR-002`).
- Coastal mangrove bio-shield restoration along estuaries (`STR-CST-001`).
- Rooftop rainwater harvesting mandatory under Tamil Nadu Building Rules (`STR-WTR-001`).

## 2. Document Alignment
Aligned with Tamil Nadu State Action Plan on Climate Change (TNSAPCC 2.0) and Greater Chennai Corporation Climate Action Plan (GCC CCAP).
